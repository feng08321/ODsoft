# 高光谱 AOD / WVOD 反演软件 使用说明书

**版本 v1.0.0** · 编写人：Liu Liying, Zheng Feng · 联系：feng1214@126.com

---

## 1. 软件概述

本软件基于高光谱太阳直接辐照度（DNI）观测数据，依据 **QX/T 69-2024
《气溶胶光学厚度 太阳光度计法》** 反演：

- 11 个特征波长（340/380/400/440/500/550/675/780/870/936/1020nm）的
  气溶胶光学厚度（AOD）时间序列与全波段 AOD 光谱
- Ångström 参数（α 波长指数、β 浑浊度系数）
- 936nm 水汽光学厚度（WVOD）与可降水量（PWV，垂直柱/斜柱双表示）
- svg 水平总辐射数据的积分产品（全谱/UV/VIS/NIR/PAR/PPFD/照度）

软件采用 Web 界面（本地服务 + 浏览器访问），支持单日数据文件的上传、
参数配置、自动 Langley 定标、反演计算、图表查看与结果导出。

## 2. 安装与启动

### 2.1 环境要求

- Windows 10/11，Python 3.10 及以上
- 依赖包见 `requirements.txt`（已锁定版本）

### 2.2 安装

```bat
pip install -r requirements.txt
```

### 2.3 启动

双击运行 `start_all.bat`：

1. 自动检查并结束占用 8000 端口的旧服务进程（保证加载最新代码）
2. 启动 FastAPI 后端服务
3. 自动打开浏览器访问 http://localhost:8000

> **注意**：每次修改过后端 `.py` 文件，都必须重新双击 `start_all.bat`
> （或重启服务）才能生效。页面显示异常时先按 **Ctrl+F5** 强制刷新浏览器缓存。

### 2.4 停止

关闭命令行窗口即可停止服务。

## 3. 界面与参数说明

页面顶部为参数控制面板，下方为结果区（Time Series / Wavelength Curve /
Raw Data / Data View 四个页签）。

### 3.1 数据输入

| 参数 | 说明 |
|---|---|
| DNI Data File | 单日观测 Excel 文件（svd 或 svg 格式），文件名须以日期开头（如 `20211109svd.xlsx`） |
| Data Type | **Direct (svd)**：直接辐射，用于 AOD/WVOD 反演；**Global (svg)**：水平总辐射，仅做积分产品，无需经纬度 |
| Exclude Periods | 人工剔除时段（HH:MM），可添加多段；剔除数据置 NaN，不参与定标与反演。结果信息区会显示实际剔除情况 |
| Data Format | 数据时段与波长范围；波长范围按文件列数自动识别（801→300–1100nm，121→280–400nm，751→950–1700nm），一般无需修改 |
| Config File | 参数配置的导入/保存（json），便于固定站点重复使用同一套参数 |

### 3.2 反演类型

- **AOD Inversion**：AOD 反演（默认）
- **Water Vapor (936nm)**：同时进行水汽反演（WVOD + PWV）
- **Ozone Inversion**：当前版本不可用（功能待重做）

### 3.3 站点参数

| 参数 | 说明 |
|---|---|
| Latitude | 纬度（°），**需准确至 0.1° 量级**，用于太阳天顶角计算 |
| Longitude | 经度（°），对结果影响很小（1°≈4 分钟太阳时） |
| Altitude | 海拔（m，必填），默认按海拔换算气压 |
| Pressure Source | 气压来源：由海拔计算（默认）或直接输入实测气压（hPa） |
| Ozone Column Amount | 臭氧柱含量（DU），用于臭氧吸收估算 |

> 太阳天顶角 θ ≥ 85° 的数据点不参与反演（自动跳过）。

### 3.4 算法选项

| 参数 | 说明 |
|---|---|
| Air Mass Formula | 大气质量数公式，默认 Kasten 1965（QX/T 公式 4） |
| Rayleigh Formula | 瑞利光学厚度公式，默认 QX/T 69-2024 公式 7 |
| Gas Absorption Correction | 气体吸收扣除，默认关闭（水汽反演要求不扣） |
| Langley Calibration | 定标开关。开启（默认）：用当日数据回归大气顶层信号 E₀，失败波长自动回退 Wehrli (1985) 标准光谱；关闭：直接使用 Wehrli 值 |
| Langley Fit Segment | 定标拟合时段，详见第 4 节 |
| Calculation Mode | **Fast**（向量化，默认，快速浏览）/ **Slow**（逐分钟，精细分析）/ **Both**（同图对比，虚线为快速版） |
| WV Baseline Method | 936nm 水汽基线方法，默认 QX/T 公式 8–10（气溶胶+分子散射基线） |
| PWV Coefficients | PWV 换算系数 a/b（默认 0.585/0.569，与仪器带宽相关，建议用探空/GNSS 标定） |

## 4. Langley 定标时段（重要）

Langley 定标从当日数据中回归大气顶层信号 E₀(λ)，是 AOD 定量反演的基准。
本软件实行**两级日级统一**：

1. **统一半日分支**：Auto 模式下先在 9 个特征波长上分别试拟合上午/下午
   两个半日段，上午达标波长数 ≥ 下午则全天统一用上午，否则统一下午
   （上午优先，上午整体不可用才选下午）。
2. **统一拟合时间窗**：在选定的半日分支内，从各波长自动收缩出的候选
   窗口中评选一个对全部波长综合最优的公共窗口（达标波长数优先、
   中位 R² 次之），所有波长在同一窗口内重拟合。

> **为什么必须统一**：各波长若各自选段，E₀(λ) 会混入不同时段的大气状态
> 差异，导致 AOD 光谱和 Ångström 指数失真。统一性优先于单波长最高 R²。

时段选项：

- **Auto（默认）**：上述自动统一选择
- **Morning only / Afternoon only**：强制使用上午/下午段
- **Whole day**：全天拟合（不推荐，上下午大气通常不对称）
- **Manual**：人工指定时段（下方输入起止时刻），用于云天或特殊日型的精细处理

## 5. 操作流程

### 5.1 svd 数据（AOD/WVOD 反演）

1. 双击 `start_all.bat` 启动服务
2. 选择数据文件，Data Type 选 Direct (svd)
3. 确认纬度/经度/海拔等站点参数（或导入配置文件）
4. 勾选需要的反演类型（AOD / Water Vapor）
5. 如需剔除云遮挡等坏时段，添加 Exclude Periods
6. Langley Fit Segment 保持 Auto（特殊日型可改 Manual）
7. 点击 **Start Inversion**，等待进度完成（Fast 模式通常数秒）
8. 在各页签查看结果，确认 Langley 诊断图质量
9. **Save Excel** 导出结果，**Save Charts** 批量保存图表

### 5.2 svg 数据（总辐射积分产品）

1. Data Type 选 Global (svg)，按钮变为 Load & View
2. 无需经纬度参数
3. 查看全谱/UV/VIS/NIR/PAR/PPFD/照度积分结果

> svg 数据中 328/349nm 坏列会自动进行波长插值后再积分。

### 5.3 三种计算模式的使用建议

- **Fast**：日常快速浏览全部日期
- **Slow**：对特定日期做精细分析
- **Both**：验证两种模式结果一致性（应基本重合）

## 6. 结果解读

### 6.1 结果信息区

显示数据日期、有效数据范围、剔除时段、Langley 定标结果摘要
（统一时段、各波长 E₀/R²/拟合窗口）等。

### 6.2 Time Series 页签

- **Irradiance Time Series**：关键波长辐照度时间序列（原始观测质量检查）
- **Langley Calibration Fits**：9 个特征波长的定标诊断图（见 6.3）
- **AOD Time Series**：AOD 时间序列。上方勾选框可显示/隐藏各波长曲线；
  纵轴支持线性/对数切换。936/1020nm 含水汽吸收，仅供参考

### 6.3 Langley 诊断图怎么看

- 横轴为大气质量数 m，纵轴为 ln(E·R²)
- **彩色点** = 参与拟合的数据，**灰色点** = 被剔除的数据
- 副标题第一行：拟合方程（截距=lnE₀，斜率=τ）与 R²；
  第二行：**实际拟合时段**与日期
- 标题标注 `[estimated 估计解]`：该波长不满足 R²≥0.9 的正常解判据，
  但满足 σ(lnE₀)≤0.01 且 R²≥0.5 的估计解判据，E₀ 可用但精度略低
- 数据点呈"人"字分叉是上午/下午大气不对称的正常表现，
  统一后所有波长应使用同一分支（标题中的 morning/afternoon 一致）
- 870nm 出现平行双线是旧批次仪器 CCD 亚像素抖动所致（见已知限制），
  不影响趋势判断

### 6.4 Wavelength Curve 页签

全波段 AOD 光谱（总光学厚度减瑞利散射）、Ångström 拟合结果。
注意水汽/氧气强吸收带内（约 690–730、760、790–870、920–980nm）
的光谱数据不可定量使用。

### 6.5 Raw Data / Data View 页签

原始光谱曲线与逐分钟数据表，用于数据质量核查。

### 6.6 PWV 子页（勾选 Water Vapor 后）

PWV 垂直柱与斜柱（=垂直柱×m）独立子图显示。

## 7. 结果导出

- **Save Excel**：导出当日结果 Excel（AOD 时间序列、AOD 光谱、
  WVOD/PWV、Langley 报告等分表）
- **Save Charts**：批量保存所有图表为图片

## 8. 常见问题（FAQ）

**Q：修改代码后重新运行，结果没有变化？**
A：后端服务需要重启（重新双击 `start_all.bat`），并且浏览器需 Ctrl+F5
强制刷新。

**Q：页面打不开 / 提示端口占用？**
A：`start_all.bat` 已自动处理 8000 端口占用；若仍失败，检查是否有其他
程序占用 8000 端口。

**Q：为什么 16:00 之后没有数据？**
A：本站西侧山体遮挡，16:00 后太阳直射信号无效，属正常观测限制。

**Q：Langley 全部波长拟合失败怎么办？**
A：全天多云/强扰动日可能全部回退 Wehrli 标准光谱，当日 AOD 绝对值
可信度降低，请结合定标报告判断；也可尝试 Manual 模式人工指定一个
相对稳定的时段。

**Q：936/1020nm 的 AOD 曲线为什么默认提示"含水汽吸收"？**
A：936nm 位于水汽吸收带内，其光学厚度受水汽主导，不代表气溶胶；
该通道用于 WVOD/PWV 反演。

**Q：estimated（估计解）的 E₀ 能用吗？**
A：可以。估计解满足 σ(lnE₀)≤0.01 的稳定性判据，仅 R² 略低
（0.5≤R²<0.9），典型如 870nm（受 CCD 抖动影响）。软件会以估计解
参与后续反演并在图中标注。

## 9. 已知限制

- 臭氧反演模块结果不可用（待重做）
- 臭氧 Chappuis 带（450–750nm）未扣除，675nm AOD 略偏高
- 水汽/氧气强吸收带内光谱数据不可定量使用
- 太阳天顶角 θ ≥ 85° 的数据点不参与反演；纬度需准确至 0.1° 量级
- 旧批次数据 870nm 通道存在 ±1 像素 CCD 时序抖动（新版 FPGA 固件
  已修复），定标走估计解判据，数据保留不修
