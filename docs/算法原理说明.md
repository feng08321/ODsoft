## 1. 总体反演链

仪器测量太阳直接辐照度（或电压信号），按 Beer-Lambert 定律，地面信号与
大气顶层信号的关系为：

```
E(λ) = E₀(λ) · esd · exp[−m · τ_total(λ)]
```

其中 E₀(λ) 为大气顶层太阳辐照度，esd 为日地距离修正因子，m 为大气质量数，
τ_total 为大气总光学厚度。反演分解链：

```
τ_total = τ_aero(AOD) + τ_R(瑞利) + τ_ab(气体吸收)
```

1. 由实测信号计算各波长总光学厚度；
2. 按气压计算并扣除瑞利散射光学厚度；
3. （可选）扣除气体吸收光学厚度（O₃、NO₂、CO₂、CH₄）；
4. 剩余部分即为气溶胶光学厚度 AOD；
5. 由 870/1020nm 建立基线，得到 936nm 水汽光学厚度 WVOD，再转换为 PWV。

## 2. AOD 反演主公式（QX/T 公式 1）

```
τ_aero(λ) = (1/m) · ln[a·V₀(λ)/V(λ)] − τ_R(λ) − τ_ab(λ)     (1)
```

- V(λ)：仪器实测信号（电压或辐照度，二者只差仪器校正系数，本质相同）
- V₀(λ)：大气顶层对应的仪器信号（定标常数），由 Langley 定标获得（第 5 节）
- a：日地距离修正系数 a = (R/R̄)² = 1/esd
- τ_R：瑞利散射光学厚度；τ_ab：气体吸收光学厚度

软件内部实现采用等价的辐照度形式 τ_total = −ln[E/(E₀·esd)]/m，E₀ 由
Langley 定标给出或回退 Wehrli (1985) 标准光谱。

## 3. 大气质量数与太阳几何（QX/T 公式 4、6）

### 3.1 太阳赤纬（Spencer 傅里叶级数，公式 6）

```
δ = 0.006918 − 0.399912cosΓ + 0.070257sinΓ − 0.006758cos2Γ
    + 0.000907sin2Γ − 0.002697cos3Γ + 0.00148sin3Γ          (6)
```

Γ = 2π(dₙ−1)/365，dₙ 为积日；公式输出为弧度。太阳天顶角 θ 由纬度、
赤纬、时角按球面天文公式计算（含经度对 120°E 的时角修正）。
θ ≥ 85° 的数据点不参与反演。

### 3.2 大气质量数（Kasten 1965，公式 4）

```
m = 1 / [cosθ + 0.15 × (93.885 − θ)^(−1.253)]               (4)
```

θ 以度为单位。可选 Kasten & Young (1989)、Young & Irvine (1967)、
简单 1/cosθ 公式（界面 Air Mass Formula 选项）。

## 4. 瑞利与气体吸收光学厚度（QX/T 公式 7、11–14）

### 4.1 瑞利散射（公式 7，默认）

```
τ_R(λ) = (P/P₀) × 0.0088 × λ^(−4.05)                        (7)
```

λ 以 μm 为单位，P 为站点气压（默认由海拔换算，可直接输入实测值），
P₀=1013.25 hPa。可选 Hansen & Travis (1974) 公式。

### 4.2 气体吸收（可选，默认关闭）

```
τ_O3(λ)  = k_O3(λ) · u_O3          (11)    τ_NO2(λ) = k_NO2(λ) · u_NO2   (12)
τ_CO2(λ) = (P/P₀) × 0.0087 × λ^(−4.09) (13)
τ_CH4(λ) = (P/P₀) × 0.0047 × λ^(−4.15) (14)
```

O₃/NO₂ 为吸收系数 × 柱含量；CO₂/CH₄ 为经验系数法。默认关闭
（水汽反演要求不扣气体）。

> 注意：臭氧 Chappuis 带（450–750nm）目前未扣除（截面表仅覆盖紫外段），
> 675nm 处 AOD 可能略偏高。

## 5. Langley 定标（V₀/E₀ 的获取）

对主公式取对数：

```
ln(V·R²) = ln(V₀·R̄²) − m · τ_total
```

在大气稳定、无云的时段内，ln(V·R²) 对 m 呈线性，回归直线外推到 m=0 的
截距即为 V₀（斜率为该时段平均总光学厚度）。

### 5.1 数据清理

Langley 法依赖"太阳无遮挡、大气条件稳定"假设，软件实施两层清理：

- **云/扰动剔除**：以表观总光学厚度的时间稳定性为判据，剔除相邻点跳变
  （默认 >0.05）及滑动窗口内标准差过大（默认 >0.02）的点
  （云遮挡瞬变、沙尘、大雾等）；
- **时段收缩**：整段拟合不达标时递归二分缩小时段（最多至 1/4），
  在最长的稳定子时段内拟合，得到各波长的候选窗口。

### 5.2 日级两级统一（v1.0.0 起）

实测大气上午/下午通常不对称（Langley 图呈"人"字分叉），若各波长
各自选段，E₀(λ) 会混入不同时段的大气状态，导致 AOD 光谱与 Ångström
指数失真。因此实行两级日级统一：

1. **统一半日分支**：9 个特征波长分别试拟合上午/下午半日段，
   上午达标波长数 ≥ 下午则全天统一用上午，否则统一下午
   （上午优先；全天 = all 或人工时段 Manual 由用户显式指定）；
2. **统一拟合时间窗**：在选定分支内，从各波长候选窗口中评选对全部
   波长综合最优的公共窗口（达标波长数优先、中位 R² 次之），
   所有波长在同一窗口内重拟合。统一性优先于单波长最高 R²。

### 5.3 分级接收判据

按以下优先级判定各波长定标结果：

1. **物理约束否决**：斜率须满足 0 < τ ≤ 1，否则拒绝（防云段假拟合）；
2. **正常解**：R² ≥ 0.9；
3. **估计解**（estimated）：σ(lnE₀) ≤ 0.01 且 R² ≥ 0.5，
   E₀ 可用但精度略低，图题与报告标注 `[estimated]`；
4. **失败回退**：均不满足则回退 Wehrli (1985) 大气顶层标准光谱值。

全天多云/强扰动日可能全部回退，当日结果可信度降低，需结合定标报告判断。

### 5.4 定标范围

- 特征波长（340/380/400/440/500/675/870/936/1020nm）：AOD 时序与 WVOD；
- 全波段（~800 个波长，向量化回归 <1 秒）：高光谱 AOD 谱。

> 水汽/氧气强吸收带内（约 690–730、760、790–870、920–980nm）Langley
> 假设不成立（光学厚度随水汽含量变化），这些波段的光谱数据不可定量使用。

## 6. 936nm 水汽光学厚度（QX/T 公式 8–10）

936nm 位于水汽吸收带内，870/1020nm 位于带外。用带外两点的
"气溶胶+分子散射"光学厚度按幂律内插出 936nm 基线：

```
α = −ln[τ_a+m(1020)/τ_a+m(870)] / ln(1020/870)              (9)
τ_a+m(936) = τ_a+m(870) × (936/870)^(−α)                    (10)
τ_H2O(936) = τ(936) − τ_a+m(936)                             (8)
```

τ_a+m = AOD + τ_R（标准方法，默认）；另有纯 AOD 基线选项：
τ_H2O = τ(936) − τ_R(936) − AOD(870)×(936/870)^(−α)。

## 7. 可降水量 PWV 的换算（QX/T 公式 5–7）

水汽透过率与仪器响应（ω = m·PWV 为斜程水汽量，τ 为 936nm 总光学厚度）：

```
T_w = exp(−a·ω^b)，ω = m·PWV                                (5)
V = V₀·R^(−2)·exp(−mτ)·T_w                                  (6)
PWV[cm] = [ (ln(V·R²/V₀) + mτ) / (a·m^b) ]^(1/b)            (7)
```

软件按垂直水汽光学厚度 WVOD = τ_H2O(936) = −ln(T_w)/m = a·m^(b−1)·PWV^b
等价反解（含 m^(b−1) 因子，不可省略）：

```
PWV[mm] = 10 × ( WVOD / (a·m^(b−1)) )^(1/b)
```

输出两种表示：**垂直柱**（PWV vertical，标准物理量）与**斜柱**
（PWV slant = m × 垂直柱，沿实际阳光斜程路径），图表独立子页、Excel 双列存储。

PWV 标准单位为 mm（垂直气柱内水汽全部凝结的液态水厚度，
1 mm = 1 kg/m²）。默认系数 a=0.585、b=0.569 取自 940nm 标准滤光片
光度计文献参数化（Bruegge/Halthore 等），与仪器带宽/光谱响应相关，
可在界面调整，建议用同期探空或 GNSS 水汽数据对本仪器拟合标定。

## 8. Ångström 参数

气溶胶光学厚度的波长依赖用 Ångström 公式描述：

```
τ_aero(λ) = β · λ^(−α)
```

对 440–870nm 的 AOD 做 lnτ–lnλ 最小二乘拟合，斜率即 α（波长指数，
反映粒子尺度：α 大→细粒子为主），截距给出 β（浑浊度系数）。

## 9. svg 总辐射积分产品

对 svg（水平总辐射）数据按波长积分输出（328/349nm 坏列先做波长插值）：

- 全谱积分（300–1100nm）
- UV（300–400nm）、VIS（400–700nm）、NIR（700–1100nm）
- PAR（光合有效辐射，400–700nm）与 PPFD（光合光子通量密度）
- 照度（按 CIE 1931 V(λ) 视见函数加权）

## 10. 算法选项一览

| 选项 | 取值 | 说明 |
|---|---|---|
| Langley Calibration | On（默认）/ Off | 开启则用当日数据回归 E₀；失败自动回退 Wehrli 标准值 |
| Langley Fit Segment | auto（默认）/ morning / afternoon / all / manual | 定标时段；auto 执行日级两级统一（5.2 节） |
| Air Mass Formula | kasten（默认）/ kasten_young / young_irvine / simple | 大气质量数公式 |
| Rayleigh Formula | standard（默认）/ hansen | 瑞利光学厚度公式 |
| Gas Correction | false（默认）/ true | 是否扣除 O₃/NO₂/CO₂/CH₄ 吸收 |
| WV Baseline Method | standard（默认）/ aod_only | 936nm 水汽基线方法 |
| Calculation Mode | Fast（默认）/ Slow / Both | 向量化快速 / 逐分钟慢速 / 两者对比 |
| PWV Coefficients | a=0.585, b=0.569（默认） | PWV 换算系数，可手动修改 |
