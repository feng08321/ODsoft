# AOD 谱修正变更摘要

日期：2026-09-16
范围：高光谱波长曲线从"大气总光学厚度"升级为"全波段 AOD 谱"，并配套实现全波段 Langley 定标

---

## 1. 变更背景

- 原"Hyperspectral Optical Depth Curve"图展示的是**大气总光学厚度**（未扣瑞利/气体），不是 AOD；
- AOD 此前只有 7 个特征波长（340/380/400/440/500/675/870nm），**没有全波段 AOD 波长分布曲线**；
- 总光学厚度曲线在部分波长（如 848nm 夫琅禾费 Ca II 线附近）出现**负值断点**（11-01 正午时刻达 347 个负值点），根源是 Wehrli 标准 E0 与仪器实际响应不匹配；
- 原 `process_hyperspectral_data` 为逐点循环（14 时刻 × 801 波长 ≈ 1.1 万次函数调用），是 AOD 模式中最慢的一环。

## 2. 变更内容

### 2.1 新增全波段 Langley 定标 `langley_calibrate_spectrum()`

位置：`process_dni_data.py` L615

- 对全部 ~801 个波长逐一回归大气顶层信号 E0（ln(E/esd) 对大气质量数 m 线性回归，截距外推 m=0）；
- **向量化云清理**：表观光学厚度矩阵的相邻点跳变（>0.05）与滑动窗口标准差（>0.02）联合剔除云遮挡/剧烈扰动点（pandas rolling，一次完成全部波长）；
- σ 迭代回归（Bouguer-Langley，2σ、最多 3 次迭代）；
- 全天拟合不达标（R²<0.85）时自动尝试**上午/下午半日段**，取 R² 较高者；
- 仍失败的波长不进入返回字典，调用方回退 Wehrli 标准值（含插值）；
- 返回 `(e0_dict, report_df)`，report 含每个波长的 e0、tau_mean、R²、拟合点数、使用段（all/morning/afternoon）。

### 2.2 `process_hyperspectral_data()` 向量化重写

位置：`process_dni_data.py` L200

- 太阳几何、E0 向量、瑞利向量按天/按波长**只算一次**；每个采样时刻全部波长一次完成反演；
- 输出新增 **`aod`** 字段：AOD 谱 = 总光学厚度 − 瑞利（− 气体，可选）；
- 保留 `optical_depths`（总光学厚度）字段供参考；
- 新增 `e0_langley` 参数接入全波段定标结果；
- 性能：单天高光谱处理从几十秒降至 **0.18 秒**。

### 2.3 服务接口（`main.py`）

- `/aod-inversion` 流程更新为：读文件 → 特征波长 Langley 定标（5–15%）→ **全波段 Langley 定标（15–30%）** → AOD 反演 → 高光谱 AOD 谱（70–98%）；
- 返回结果中 `wavelength_series` 改为 AOD 谱，新增 `wavelength_series_total`（总光学厚度）；
- 进度条阶段同步更新。

### 2.4 前端（`frontend_english.html`）

- 图标题改为 "Hyperspectral AOD Spectrum (日期)"，纵轴标签改为 AOD；
- 典型波长圆圈标记（340/380/400/440/500/675/870/936/1020nm）与对数/线性纵轴切换功能保持不变。

## 3. 验证结果（2021-11-01，正午 12:00）

| 波长 | 旧版（Wehrli） | 新版（全波段 Langley） |
|---|---|---|
| 440 nm | 0.029 | 0.194 |
| 500 nm | 0.025 | 0.141 |
| 675 nm | **-0.029** | 0.073 |
| 870 nm | **-0.039** | 0.036 |
| AOD 谱负值点数 | 347 | 21 |

- 全波段定标成功 756/801 波长（94%），成功段分布：下午段 671、上午段 574、全天段 80；
- AOD 谱随波长单调递减，符合气溶胶谱物理特征；675/870nm 负值消除；
- 剩余 21 个负值点集中在水汽/氧气强吸收带内（720/760/820/940nm），属 Langley 假设不适用的预期范围，不可定量使用。

## 4. 使用注意事项

1. 高光谱 AOD 谱中，**水汽/氧气吸收带内**（约 690–730、760、790–870、920–980nm 等）数据不可用于定量分析，看图时请避开；
2. 全天多云/沙尘等不稳定天气下 Langley 定标可能大量失败并回退 Wehrli 值，建议结合定标报告判断当日曲线可信度；
3. 批处理脚本 `recompute_all.py` 未包含高光谱 AOD 谱输出，本次变更仅影响 Web 接口；
4. 重启 `start_all.bat` 后生效，前端需 Ctrl+F5 强制刷新。
